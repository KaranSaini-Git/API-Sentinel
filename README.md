# API Sentinel

API Sentinel is a backend middleware project designed to add an extra layer of security, control, and monitoring to APIs. It helps developers manage and protect their APIs through a centralized system without having to implement these features separately in every application.

The project aims to provide features such as:

- **API Key Management:** Generate and manage API keys to control access to protected endpoints.
- **Authentication:** Verify incoming API requests using API keys and authentication mechanisms.
- **Rate Limiting:** Restrict excessive requests to prevent API abuse and overloading.
- **Request Logging:** Record incoming requests and their details for monitoring and debugging.
- **Performance Monitoring:** Track API response times and request performance.
- **Analytics:** Provide insights into API usage and request activity.

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- Redis
- JSON Web Tokens (JWT)

## Project Goal

The goal of API Sentinel is to build a reusable API management and protection layer that developers can integrate into their applications to improve security, monitor usage, and maintain better control over their APIs.
